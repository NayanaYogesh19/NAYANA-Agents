
# Reach, Engagement & Follower Analytics Agent

Multi-platform analytics agent built using:
- LangChain
- FastAPI
- Selenium
- Apify (LinkedIn)
- Pandas
- BeautifulSoup

## Platforms Supported
- Instagram
- Facebook
- LinkedIn
- YouTube

## Features
- Followers extraction
- Average likes estimation
- Average comments estimation
- Post type analysis
- Creative angle analysis
- Engagement analysis
- Monthly trend-ready analytics JSON

Fill your `.env` before running.
